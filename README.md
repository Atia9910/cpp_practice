# cpp_practice

A collection of C++ practice programs covering fundamentals like random number generation, arrays, string handling, and standard library features.

## Programs

- **coin_flip_simulation.cpp** — Simulates biased coin flips using `bernoulli_distribution`.
- **SIx_sided_dice_rolling.cpp** — Simulates 10,000 six-sided die rolls and tallies results.
- **file1.cpp** — Rock, Paper, Scissors game against a fixed computer choice.
- **file2.cpp** — Simple password login system with limited attempts.
- **file3.cpp** — Fake Ghanaian phone number generator (MTN, Telecel, AirtelTigo).
- **orderingnumbers.cpp** — Hollow Knight-themed username/password generator.
- **radix_property.cpp** — Demonstrates `numeric_limits` radix for int and double.
- **manus.cpp** — Simple function declaration/definition example (multiplication).
